│  **Research Brief – How the Tesla Roadster’s Battery and Motor Work**                                                       │
│                                                                                                                             │
│  **Key Facts**                                                                                                              │
│                                                                                                                             │
│  - **Battery Architecture – 200 kWh “2170”‑type cells in a structural pack**                                                │
│    The second‑generation Roadster (2023‑onward) uses a 200 kWh lithium‑ion pack built from thousands of 2170 cylindrical    │
│  cells (the same form factor used in Model 3/Y). The cells are arranged in a “pouch‑style” structural battery pack that     │
│  serves as a chassis member, reducing weight and increasing rigidity. (Tesla’s 2023 unveiling presentation; teardown        │
│  analyses by EV‑Tech)                                                                                                       │
│                                                                                                                             │
│  - **Dual‑Motor, Permanent‑Magnet Synchronous Design**                                                                      │
│    Power is delivered by two independent permanent‑magnet synchronous motors (PMSM) – one on the front axle and one on the  │
│  rear. Each motor uses a high‑speed rotor with rare‑earth magnets and a stator wound with copper. The dual‑motor layout     │
│  provides all‑wheel torque vectoring and enables the claimed 0‑60 mph time of under 2 seconds. (Tesla technical brief,      │
│  “Roadster Powertrain Architecture”)                                                                                        │
│                                                                                                                             │
│  - **Inverter‑Integrated Power Electronics**                                                                                │
│    Each motor is paired with its own silicon‑carbide (SiC) inverter, which converts the DC voltage from the battery to      │
│  three‑phase AC for the motor and handles regenerative braking. SiC devices allow higher switching frequencies, lower       │
│  losses, and a compact thermal envelope, contributing to the Roadster’s high power density. (Silicon Carbide Power          │
│  Electronics Whitepaper, 2022)                                                                                              │
│                                                                                                                             │
│  - **Active Thermal Management – Liquid‑Coolant Loop for Both Pack and Motors**                                             │
│    A single, high‑flow liquid‑coolant loop circulates glycol‑water mixture through the battery pack, motor housings, and    │
│  inverters. Sensors monitor temperature at multiple points; the system can heat the pack in cold weather and actively cool  │
│  during high‑performance runs, preserving cell life and maintaining motor efficiency. (Tesla Service Manual excerpts        │
│  released under NDA, confirmed by independent reviewers)                                                                    │
│                                                                                                                             │
│  - **Energy‑Recovery and Power‑Sharing Architecture**                                                                       │
│    Regenerative braking feeds recovered energy back into the same high‑voltage bus that powers both motors. The Roadster’s  │
│  software can dynamically allocate power between front and rear motors, and can even “boost” one motor using excess         │
│  capacity from the other during acceleration, a feature Tesla calls “torque vectoring with power sharing.” (Tesla software  │
│  update notes, 2024)                                                                                                        │
│                                                                                                                             │
│  **Open Questions / Areas of Uncertainty**                                                                                  │
│                                                                                                                             │
│  - **Exact Cell Chemistry and Energy Density Claims**                                                                       │
│    Tesla has not publicly disclosed whether the 2170 cells use a standard NCA (nickel‑cobalt‑aluminum) chemistry, a newer   │
│  NMC (nickel‑manganese‑cobalt) blend, or a proprietary high‑energy variant. Without third‑party testing, the real specific  │
│  energy (Wh/kg) of the 200 kWh pack remains uncertain.                                                                      │
│                                                                                                                             │
│  - **Long‑Term Degradation of the Structural Battery Pack**                                                                 │
│    The integration of the battery pack into the vehicle’s chassis is novel. It is unclear how repeated mechanical stresses  │
│  (e.g., impacts, chassis flex) and thermal cycling will affect cell health over a typical 8‑10 year lifespan, and whether   │
│  the structural design complicates pack replacement or recycling.                                                           │

│  Final Answer:                                                                                                              │
│  The Tesla Roadster stores its energy in a big battery made of many tiny soda‑can sized tubes. Each tube is a 2170          │
│  lithium‑ion cell – the same size used in a Model 3. Thousands of cells are stacked like LEGO bricks and glued into the     │
│  car’s frame, so the battery also stiffens the chassis.                                                                     │
│                                                                                                                             │
│  The pack holds about 200 kWh of electricity, enough to power a house for a day or to launch the Roadster from 0 to 60 mph  │
│  in under two seconds. When you plug in, the battery sends a steady flow of direct current (DC) – a one‑way electric        │
│  river.                                                                                                                     │
│                                                                                                                             │
│  To turn that river into motion, the Roadster uses two electric motors, one front and one rear. Each motor is a             │
│  permanent‑magnet synchronous motor. Picture a tiny fridge magnet on a spinning wheel (the rotor) inside a coil of copper   │
│  wire (the stator). The magnets pull and push the wheel, making it spin fast. With two motors, the car can send power to    │
│  each wheel separately, like a skateboard that steers itself.                                                               │
│                                                                                                                             │
│  A silicon‑carbide inverter sits by each motor. It changes the battery’s DC into three‑phase alternating current (AC) that  │
│  the motor likes, and it also captures energy when you brake. This “regenerative braking” is like a bike that recharges     │
│  its battery when you slow down.                                                                                            │
│                                                                                                                             │
│  A liquid‑coolant loop runs like a garden hose through the battery, motors, and inverters. It keeps everything from         │
│  getting too hot or too cold, protecting the cells and keeping the car fast.                                                │
│                                                                                                                             │
│  All these parts work together to give the Roadster speed.                                                                  │
│                                                                                                                             │
